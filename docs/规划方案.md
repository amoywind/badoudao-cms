### 定位话术

产能区间而非固定数字，本身就是个优势：**简单款能排到 2000/天，复杂款 1000/天，交期可承诺**。这比"日产能 5000 支"的空头承诺更可信，因为买家能问出具体数字并验证。

目标客户画像：
- **中小跨境卖家 / Amazon 卖家** — 试新款不想背大库存
- **礼品定制商 / Promotional Products 渠道** — 贴牌 LOGO、小批量多款式
- **家居装饰零售商 / 买手店** — 找有设计感且可小批量补货的供应商
- **品牌初创团队** — 第一年单量不大但看重配合度

**主动排除**：Kmart、Walmart 类大批量连锁零售商。接他们的单会挤占产能，反而抬高 MOQ 门槛，挡住真正的目标客户。

## 二、关键词策略：wall clock 分层打法 ★

### 关键判断

"wall clock" 泛词搜索量高，但 **SERP 已被 Amazon、Walmart、Target 等零售站和家居装饰内容站占满**。搜这个词的买家意图是"我要买一个钟"，不是"我要找工厂"。

对 MOQ 500 的产品，打泛词等于**花力气引来零散个人买家**——询盘数量上去了，成交率却崩。

但完全不碰 wall clock 又可惜了它的搜索量。解法是**分层**：

```
泛词拿曝光  →  采购词收询盘
```

分类页标题与 H1 保留 Wall Clock 承接泛词流量，**正文第一段和询盘 CTA 立即切换到批发采购语境**。这样既吃到泛词的量，又不过滤掉 B2B 买家。

### 关键词分层表

**第 0 层：泛词锚点（拿曝光，不主攻）**
```
wall clock                wall clocks              decorative wall clock
```

> 用在分类页 H1、Title、URL 中。不为这些词单独写文案，不投入资源。

**第 1 层：wall clock + 采购修饰（★ 核心机会）**
```
wall clock wholesale            wall clock manufacturer
wall clock supplier              wall clock bulk
wholesale wall clocks            wall clock factory
custom wall clock manufacturer   wall clock distributor
```

> **这是本次分析最重要的结论**。这些词借到了 wall clock 的搜索量，同时保留了明确的买家意图，竞争度远低于泛词。全部产品页与分类页围绕这一层布局。

**第 2 层：quartz wall clock 精准词（防守区，转化最高）**
```
quartz wall clock manufacturer         quartz wall clock wholesale
custom quartz wall clock              silent quartz wall clock
12 inch quartz wall clock wholesale   quartz wall clock supplier
low MOQ quartz clock manufacturer     custom logo quartz wall clock
wood MDF wall clock wholesale         metal wall clock manufacturer
```

> 搜索量小但竞争最小，转化率最高，是询盘的主要来源。

**第 3 层：其他品类（分类页承接）**
```

```

**第 4 层：决策期内容（博客承接）**
```

```

### 一个需要警惕的数据

行业数据显示石英钟品类近半年搜索兴趣**下滑约 92%**，且呈明显季节性（3 月高、9 月低）。

这不是放弃理由，但意味着：
- **不要用自然流量增长做 KPI**，要用询盘数
- **旺季（Q1）前 2 个月就要发内容**，3 月前内容已上线才能吃到峰值
- 产品线里**闹钟和机芯配件占比要提高**，抗单一品类波动

## 三、认证策略修正 ★

### 真实情况

- **石英钟成品本身没有强制认证要求**
- **所用机芯具备 CE 和 RoHS**
- 客户如有需要，**可临时办理所需认证**

### 策略调整（重要）

之前把认证做成核心信任锚点是**方向错误**。既然成品无强制认证要求，把证书当卖点反而会引来懂行的买家质疑。

**新策略：把"认证"从信任锚点改为服务能力。**

| 原来的做法 | 修正后的做法 |
|---|---|
| 首屏展示认证 logo 作为实力证明 | 移至FAQ 与质量控制页 |
| 暗示"我们产品有认证" | 明确说明"成品无强制认证要求，机芯已有 CE / RoHS" |
| 作为被动信任信号 | 作为**主动服务能力**：客户需要时可临时办理 |

**这反而是个差异化卖点**：很多工厂办证要 15–20 天，"可临时办理"是实打实的 responsiveness。写法示例：

> Quartz clocks themselves do not require mandatory certification. The movements we use are CE and RoHS compliant. If your market or retailer requires specific documentation, we can arrange certification on request — tell us what you need and we'll quote the timeline.

**必须避免的表述**：不要说"我们的产品通过 CE 认证"（不准确），要说"所用机芯符合 CE / RoHS 要求"。

### 新的信任锚点（替换认证）

既然认证不能当锚点，信任靠什么？**全部换成可验证的事实**：

- 日产 1,000–2,000 支（具体数字，随产品难度浮动）
- 打样 7–10 天 · 交期 20–45 天（按难度）
- MOQ 500 件公开
- 四阶段 QC 流程（IQC / IPQC / FQC / OQC）
- 产线实拍 + 车间视频帧
- 可临时办理认证（作为服务说明）

## 六、管理后台规划 ★

技术选型：**Payload CMS 3.x**，与前端 Next.js 同一代码库。

### 6.1 权限角色设计

| 角色 | 权限 |
|---|---|
| **Admin** | 全部权限，含系统设置、成员管理、删除 |
| **Sales** | 询盘读写。产品只读。内容只读。无系统设置 |
| **Content** | 产品/博客/页面读写。分类读写。询盘只读 |
| **Factory** | 库存、MOQ、交期读写。产品核心字段只读。**看不到售价** |
| **Viewer** | 全站只读 |

> **售价与成本分离存储**。Factory 看不到售价，Sales 看不到成本。

### 6.2 仪表盘

- **询盘卡片**：今日新增 / 本周新增 / 待跟进 / 超 24h 未回复标红
- **近 7 日询盘趋势**，按产品类别拆分
- **产品表现 Top 10**：浏览量 → 转化率排序
- **待办提醒**：无库存、缺图片、SEO 未填写、超 48h 未回复
- **库存预警**：低于安全阈值
- **快捷入口**：新建产品 / 新建文章 / 查看询盘

### 6.3 产品管理 ★

**列表页**
- 列：图片 / 名称 / 分类 / 型号 / 出厂价 / MOQ / 库存 / 状态 / SEO 完整度 / 更新时间
- 筛选：分类、状态、库存区间、价格区间、缺图、SEO 未完成
- 批量操作：上下架、改分类、调价、导出
- 视图切换：表格 / 卡片
- 快速搜索：名称、型号、SKU，支持拼音首字母

**编辑页 Tab**

| Tab | 内容 |
|---|---|
| **基本信息** | 名称、型号/SKU、slug、分类、标签、状态 |
| **规格参数** | 可自定义字段（直径、厚度、重量、机芯类型、电池、材质、玻璃类型…），支持**参数组模板复用** |
| **定制选项** | LOGO 位置、印刷工艺、可选颜色、包装方式、可否混款。**同时驱动前端定制选择器** |
| **价格与 MOQ** | 阶梯价格、出厂价 EXW、MOQ、打样周期、交期。成本价仅 Admin 可见 |
| **库存** | 可售、在途、锁定、安全阈值 |
| **图片与视频** | 见 6.4 |
| **SEO 设置** | 标题、描述、URL、焦点关键词、Schema 类型、收录开关、Meta 图 |
| **关联内容** | 相关产品（同分类自动推荐 + 手动）、所属博客 |
| **操作日志** | 谁在何时改了什么，字段级对比 |

**批量导入**：Excel/CSV 导入，模板下载，导入前校验预览，错误行单独列出。

### 6.4 图片管理 ★

**媒体库（独立模块，全站共用）**
- **上传**：拖拽批量、自动压缩、多尺寸生成（400/800/1200/2000）、WebP 转换、主色提取
- **目录树**：无限层级 + 标签双维度
- **批量操作**：重命名、改目录、加标签、删除（回收站可恢复）
- **智能处理**：自动去背景（透明底）、智能裁剪、白底处理、水印
- **使用追踪**：每张图被哪些产品/页面引用，删除前提示，防止前台图片缺失
- **CDN 与用量**：存储占用、流量统计

**产品图在编辑页内**
- 拖拽排序，第一张自动设为主图
- 多角度 / 尺寸对比 / 细节 / 场景分组
- 每张图独立填 alt 文本
- 缺图产品在列表页标记，进入待办

| 模块 | 功能 |
|---|---|
| **页面** | 关于我们、工厂、质量控制、认证说明、小批量优势。支持可视化区块编辑，非技术人员可自行调整首页段落顺序 |

### 6.6 询盘管理 ★

**列表页**
- 字段：时间 / 姓名 / 公司 / 邮箱 / 国家 / 关注产品 / 数量 / 定制需求 / 负责人 / 状态
- 状态流转：`新询盘 → 已联系 → 已报价 → 谈判中 → 成交 / 流失`

## 八、需要确认的事项

1. **产能浮动的具体规则** — 简单款/复杂款分别是多少？页面上的产能区间怎么表述最准确？
2. **产品数量** — 实际有多少 SKU 可上架？
3. **英文副名** — Badoudao 拼音在欧美买家认知里无含义，是否配副名（如 Badoudao Clocks）
4. **联系方式** — 邮箱、电话、WhatsApp、工厂地址
5. **品牌色** — 目前原型用深绿 + brass，可调整
6. **MOQ 与产能的关系** — 500 MOQ 时能否达到 1000/天？若达不到，需如实调整
